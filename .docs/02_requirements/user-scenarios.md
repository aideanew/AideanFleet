## 一、用户需求场景（5 种典型）

### 场景 1：网站开发

**用户画像**：小团队技术负责人，需要快速搭建公司官网。

**对话输入**：
> "帮我建一个公司官网，首页有产品介绍、团队页、联系方式，用 Vue3 + TailwindCSS"

**AideanFleet 处理流程**：
1. Manager intake → 识别为"新项目"，创建 P-001
2. 三级计划：阶段1=前端骨架 → 阶段2=页面实现 → 阶段3=部署配置
3. 阶段1 任务：T-001 初始化 Vue3 项目 / T-002 配置 TailwindCSS / T-003 设计路由
4. 派工给执行体（opencode/codex），每个任务产出代码 + 六节报告
5. 机器门验证：文件存在性 + 语法检查
6. 人工审查：确认页面效果

**验收标准**：
- 项目可 `pnpm dev` 启动
- 3 个页面路由可访问
- 六节报告完整

---

### 场景 2：数据处理

**用户画像**：数据分析师，需要处理 CSV 数据并生成报表。

**对话输入**：
> "我有一个 sales.csv，帮我写个 Python 脚本，按月份汇总销售额，输出图表"

**AideanFleet 处理流程**：
1. Manager intake → 创建项目
2. 计划：阶段1=数据读取+清洗 → 阶段2=聚合统计 → 阶段3=可视化
3. 派工 → 执行体生成 Python 脚本
4. 机器门：脚本可执行 + 输出文件存在
5. 审查：数据准确性

---

### 场景 3：API 服务开发

**用户画像**：后端开发者，需要快速搭建 REST API。

**对话输入**：
> "用 FastAPI 建一个用户管理 API，CRUD 接口，SQLite 存储"

**AideanFleet 处理流程**：
1. intake → 创建项目
2. 计划：阶段1=数据模型 → 阶段2=API 路由 → 阶段3=测试用例
3. 并行派工：T-001 定义模型 / T-002 写 CRUD 路由
4. 机器门：API 可启动 + 返回正确状态码
5. 审查：接口语义正确

### 场景 5：DevOps 自动化

**用户画像**：运维工程师，需要编写自动化脚本。

## 二、管理者场景（控制台使用）

### 场景 A：首次启动

**操作**：`make run` → 浏览器打开 http://127.0.0.1:5000
**期望**：
- 锁屏页面（输入 token 解锁）
- 解锁后看到总览页（项目列表 + 进度条）
- 无项目时显示空状态引导

### 场景 B：对话下达需求

**操作**：在对话页输入需求 → 切换到 auto 模式
**期望**：
- Manager intake 识别意图，创建项目
- 总览页出现新项目卡片
- 任务进度实时更新（WebSocket 推送）
- 可随时切换到 step 模式人工确认

### 场景 C：监控执行进度

**操作**：在总览页查看正在执行的项目
**期望**：
- 看到三级大纲（阶段 → 任务 → 子任务）
- 每个任务有状态标签（DRAFT/DOING/SUBMITTED/REVIEWING/DONE）
- 点击任务可展开六节报告
- 事件流实时滚动（events.jsonl 推送）

### 场景 D：人工审查

**操作**：任务进入 SUBMITTED 状态 → 切换 step 模式
**期望**：
- 控制台弹出审查确认
- 可查看执行体产出的代码 + 报告
- 确认通过 → 状态变为 DONE
- 驳回 → 状态变为 REWORK，重新派工

### 场景 E：模型与角色管理

**操作**：在模型页配置角色 → 模型映射
**期望**：
- 可为 Manager / Executor / Reviewer 选择不同模型
- 模型切换在下一个任务生效（ADR-028）
- 配置持久化到 .env

### 场景 F：执行体管理

**操作**：在执行体页查看已注册适配器
**期望**：
- 列表显示适配器名称、命令、状态
- 可设置默认执行体
- 可查看执行体的运行时信息（PID、运行时长）

### 场景 G：异常处理

**操作**：执行体执行失败
**期望**：
- 任务状态变为 BLOCKED
- 控制台显示错误信息
- 可手动重试或跳过
- 事件流记录 task:blocked_release 事件

### 场景 H：用量与预算

**操作**：在消息页查看用量统计
**期望**：
- 显示 token 消耗、任务数、成功率
- 预算阈值告警
- 可导出用量报告
