可参考：
- **CloudBase Agent SDK**
  - 标识：Official（官方）
  - 技术标签：JavaScript、多轮对话、工具调用、ACP 协议
  - 描述：腾讯云官方 SDK · envId 一行配置接入 CloudBase 资源

- **LangGraph (JavaScript)**
  - 标识：开源框架
  - 技术标签：JavaScript、多步骤、条件分支
  - 描述：状态图引擎，适合显式编排多步骤、条件分支、HITL 审批

- **LangGraph (Python)**
  - 标识：开源框架
  - 技术标签：Python、多步骤、条件分支
  - 描述：状态图引擎，适合显式编排多步骤、条件分支、HITL 审批

- **LangChain**
  - 标识：开源框架
  - 技术标签：JavaScript、工具调用、RAG
  - 描述：最流行的开源 AI 框架，生态最广，适合自由组合工具

- **Crew AI**
  - 标识：开源框架
  - 技术标签：Python、多 Agent、角色化
  - 描述：多 Agent 协作，把团队拆成角色化的子 Agent 分工合作
