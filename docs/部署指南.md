# AideanFleet 部署指南（REL-01 · 版本 0.3.0）

> 目标：在新 Windows 机器上 **≤10 分钟** 完成安装并一键启动。
> 适用：Windows 10/11 + Python 3.10+（本项目开发基线 3.12）。Phase 2 功能出口依据见
> [验收清单-Phase2.md](验收清单-Phase2.md)；执行体 CLI 的安装与决策依据见
> [CLI安装决策单.md](CLI安装决策单.md)（可选，未装 CLI 时执行体走 stub/适配器降级，控制台本身可用）。

## 一、前置条件（约 2 分钟）

1. 安装 Python 3.10+（勾选 *Add python.exe to PATH*），验证：

   ```text
   python --version      # 期望 ≥ 3.10
   ```

2. （可选）安装执行体 CLI 并配置到 PATH——步骤与决策点见《CLI安装决策单.md》。
   跳过不影响控制台/调度/治理启动，仅影响真实执行体可用性。

## 二、获取源码并创建虚拟环境（约 2 分钟）

```bat
git clone <仓库地址> AideanFleet        # 或直接拷贝源码目录
cd AideanFleet
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e .
```

`pip install -e .` 依据 `pyproject.toml` 安装本项目（fastapi/uvicorn 依赖自动带上），
并注册 `fleet` 命令（入口 `fleet.launcher.cli_start:main`，等价 `python -m fleet.launcher.cli_start`）。

## 三、初始化配置（约 2 分钟）

1. 生成 `.env`（复制模板，首次启动也会自动生成）：

   ```bat
   copy .env.example .env
   ```

2. 编辑 `.env`，至少检查三处：

   | 键 | 说明 |
   |---|---|
   | `[basic] FLEET_ALLOWED_ROOTS` | 允许作为项目 workspace 的根目录（逗号分隔），**必须配置**，否则项目注册会被拒 |
   | `[model_pool] FLEET_MODEL_<i>_API_KEY` | 一律填 `${环境变量名}` 占位，真值放系统环境变量；**禁止明文** |
   | `[settings] FLEET_SETTINGS_TASK_STUCK_SECONDS` | 卡死检测阈值，默认 1800 秒，可按需调整 |

3. 可选开关（遵循既有 `FLEET_SCHEDULER` 模式，缺省关闭）：

   | 环境变量 | 说明 |
   |---|---|
   | `FLEET_SCHEDULER=1` | 控制台进程内启动常驻调度循环 |
   | `FLEET_WATCHDOG=1` | launch_core 拉起 watchdog 独立进程守护控制台（连续 3 次探活失败自动重启，5 分钟内 >3 次停止拉起等人工） |

   设置方式（watchdog 开启示例）：`set FLEET_WATCHDOG=1`（CMD）或 `$env:FLEET_WATCHDOG="1"`（PowerShell）。

## 四、一键启动（约 1 分钟）

```bat
.venv\Scripts\python.exe -m fleet.launcher.cli_start
```

或使用已注册的命令：`fleet`。启动器走统一 9 步流程（env probe → 端口预检 → .env 检查 →
启动控制台 → 启动 Manager 网关 → 健康检查 → 项目注册 → 打开浏览器 → 事件监控；
`FLEET_WATCHDOG=1` 时随后拉起 watchdog）。完成后浏览器自动打开 `http://127.0.0.1:5000`。

手工单独启动控制台（调试用）：

```bat
.venv\Scripts\python.exe -m fleet.console.server
```

## 五、启动后自检（约 1 分钟）

```text
GET http://127.0.0.1:5000/api/health
→ {"version":"0.3.0","db":true,"events":true,"config":true}
```

四键全 true 即健康。数据全部落在 `data/`（events.jsonl / SQLite / projects/ / memory/ / archive/），
不出本机。

## 六、常见问题

| 现象 | 处置 |
|---|---|
| 端口 5000/9900 被占 | `.env` 改 `FLEET_CONSOLE_PORT`，或启动器提示换端口 |
| 项目注册失败：不在允许根目录 | `.env` 的 `FLEET_ALLOWED_ROOTS` 加上项目路径根 |
| 控制台进程崩溃反复 | watchdog 自动拉起；若触发防风暴（rel:escalate 事件），人工排查后重启 launch_core |
| 事件文件过大 | 无需处理：server 启动时自动按月轮转到 `data/archive/events-YYYYMM.jsonl.gz`（seq 全局连续） |
| 卡死任务 | DOING 超 `FLEET_SETTINGS_TASK_STUCK_SECONDS` 发 task:stuck，超 2 倍自动 BLOCKED，人工释放回派工轨道 |
| pip 安装报 HTTP 403（国内镜像被代理拦截） | 追加 `-i https://pypi.org/simple` 换官方源（试装实测：清华镜像 403，官方源 22s 装完） |

## 七、版本与升级

- 版本统一记录在 `pyproject.toml` 与控制台 `/api/health` 返回体（当前 **0.3.0**）。
- 升级：拉取新源码后重跑 `.venv\Scripts\python.exe -m pip install -e .`；
  SQLite 轻迁移在 `db.init_db()` 启动时自动完成，无需手工动库。
