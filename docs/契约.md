# AideanFleet 契约（活文档）

> 本文件不再是 FROZEN 文档：契约由测试守门（import 边界 + e2e），此处只做人类可读的快照。
> 改动契约时先改测试再改文档，避免"文档冻结、代码漂移"。

## 1. Kernel todo 生命周期

```
open ──claim──▶ claimed ──▶ running ──▶ verifying ──▶ done
  ▲                │           │           │
  │ lease_expired  │           │           ├─▶ (successor) ─▶ superseded + 新 open todo（同 lineage）
  └────────────────┴───────────┴───────────┤
                                           ├─▶ blocked   ──reopen──▶ open
                                           └─▶ needs_user ──reopen──▶ open
```

- 写回唯一入口：`kernel.transition(todo_id, TurnResult)`；verdict ∈ done/successor/blocked/needs_user。
- `done` 只接受 verifying 状态；exec 类 todo 无 verify 命令且无证据 → 拒绝写回。
- 同一 lineage attempt 轮数 ≥ `lineage_limit`（默认 4）→ successor 请求自动转 `needs_user`。
- 租约：claim 默认 15 分钟，流式执行中续约；过期由 `requeue_expired_leases` 回收（worker 死亡安全）。
- 计费：验证通过并写回 done 才 `quota.used+1`；额度耗尽的角色不再派发。

## 2. verify 命令约定（A5）

- verify 必须是**真实命令数组**（构建/测试/lint），禁止"文件存在即通过"。
- `{python}` 占位符在执行时替换为 Fleet 自身解释器（`gates.verify.run_command`），
  避免 Windows 裸 `python` 解析到 Store 占位 stub。
- 内置两把门：`python -m fleet.gates.doclint docs/design.md`（设计文档实质校验）、
  `python -m fleet.gates.project_gate`（真实构建/编译/入口产物校验，cwd=工作区）。
- 证据落盘：`data/evidence/<todo>/gate.json` + `harness_output.txt`。

## 3. fleet.toml 键（优先级 env > toml > 默认）

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| workspace.allowed_roots | list | [仓库根] | 项目白名单 |
| models.<name>.base_url / model_id / api_key_env / priority | str/int | 无 | OpenAI 兼容模型池 |
| roles.<name>.harness | list[str] | [claude,codex,opencode] | 执行体链（自动降级） |
| roles.<name>.models | list[str] | [] | 模型链 |
| runtime.scheduler | str | auto | auto/step/off |
| runtime.lease_minutes | int | 15 | 认领租约 |

## 4. HTTP API（kernel 投影，会话保护）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/kernel/attention | 注意力队列：待决策/运行中/阻塞/刚完成 |
| GET | /api/kernel/todos?goal_id=&status= | todo 列表 |
| GET | /api/kernel/events?limit= | 事件流（含未发布数） |
| POST | /api/kernel/todos/{id}/reopen | typed 动作：人工解除 blocked/needs_user |

宿主内驱动（P4）：`fleet next --agent <host> --json` 认领并打印 packet；
`fleet writeback --todo <id> --verdict <v> --note <text> [--evidence <file>]` 写回。

## 5. 旧链路兼容面

- 旧 10 状态机（DRAFT→…→DONE，`data/fleet.db`）与 dispatcher/scheduler/reviewer 继续可用；
  派工 prompt 的 verify_cmd 同样支持 `{python}` 占位。
- 角色适配器降级链：任务 adapter → 角色 adapter → role_adapters.json 链 → `direct`（模型池直连），
  降级发 `adapter:degraded` 事件；全不可用才 BLOCKED（C2）。
- 控制台仍是 .env 的唯一写者（`POST /api/config/{section}`，白名单字段、拒绝明文密钥）。
