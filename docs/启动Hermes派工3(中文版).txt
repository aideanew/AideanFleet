```text

进度实时写 POST http://127.0.0.1:5000/api/launch-event 并在对话插一行，终局输出
| 角色 | 平台 | 模型 | 任务 | 评分 | 完成度表（协议 §14）。

[fleet-launch]
project: AideanBot
```

## 二、T0–T10 验收测试命令（第三方工具执行）

```powershell
# T0 版本门
curl.exe -s http://127.0.0.1:5000/api/health
# PASS: version="3.1.0-launchbus" 且 launch_routes 含两条新路由；无则旧进程，停测。

# T1 回归·计划快照
curl.exe -s "http://127.0.0.1:5000/api/plan?project=P-004"
# PASS: 200，project="P-004"，tasks 含 T-026/T-027/T-028/T-029，每任务有 id/state/assignee/reviewer/verify_cmd。

# T2 回归·事件流旧字段
curl.exe -s "http://127.0.0.1:5000/api/events?project=P-004&since=0&limit=3"
# PASS: 200，顶层含 seq/project/events；events 非空则每条必含旧字段 seq/timestamp/actor/action/taskId/summary/url。

# T3 新功能·BOOT 解析
curl.exe -s "http://127.0.0.1:5000/api/launch-resolve?project=P-004&mode=plan&port=3333"
# PASS: 200 JSON，ok=true, mode=plan, ui_url=http://127.0.0.1:3333,
#       profile_source=projects/P-004/project.json, missing=[]。返回 500/HTML 即 FAIL。

# T4 新功能·未知项目机读错误
curl.exe -s "http://127.0.0.1:5000/api/launch-resolve?project=P-999"
# PASS: 200 + ok=false + reason=project_not_found。404/500/HTML 即 FAIL。

# T5 新功能·事件总线（A写 B新索引 C旧流）
curl.exe -s -X POST http://127.0.0.1:5000/api/launch-event -H "Content-Type: application/json" -d "{\"project\":\"P-004\",\"phase\":\"third_party_probe\",\"detail\":\"third_party_probe_DO_NOT_TRUST\",\"role\":\"worker-b\",\"cli\":\"claude\",\"model\":\"claude-default\",\"percent\":\"0\"}"
# A PASS: {"ok":true,...}
curl.exe -s "http://127.0.0.1:5000/api/launch-event?project=P-004&since=0&limit=5"
# B PASS: 尾条 action=launch:third_party_probe 且带 phase/cli/model 字段
curl.exe -s "http://127.0.0.1:5000/api/events?project=P-004&since=0&limit=5"
# C PASS: 同样能读到该条（向后兼容），旧字段一个不少。

# T6 非法事件被拒且不污染审计
curl.exe -s "http://127.0.0.1:5000/api/events?project=P-004&since=0&limit=1"
# 记下返回的 seq 为 S
curl.exe -s -X POST http://127.0.0.1:5000/api/launch-event -H "Content-Type: application/json" -d "{\"phase\":\"bad_probe\",\"detail\":\"x\"}"
# PASS: {"ok":false} + HTTP 400
curl.exe -s "http://127.0.0.1:5000/api/events?project=P-004&since=S&limit=5"
# PASS: 顶层 seq 未增长、events 无非预期新行。

# T7 重试口径（读配置）
# 打开 fleet/configs/model-pool.json → retry.rule 必须是"10 秒 × 10 次 → 换模型"，
# 且 hard_signals 含 401/402/403/quota_exhausted/model_not_found（硬失败直接换不空耗 10 次）。

# T8 完成度表契约（读配置）
# 打开同一文件 final_report_contract：columns 必须= ["角色","平台","模型","任务","评分"]，
# grade_scale= 圆满/有返工/部分完成有缺口/受阻未产出/未派工，且禁止自评。

# T9 模型池探活
python E:\Code\AideanCompany\fleet\tools\probe_pool.py
# PASS: 退出 0；amd/nvidia/modelscope/sensenova/agnes=ok；bai 401、v3 no_key 属预期
#（测试禁 GPT-6 且 bai key 待更新），写明"不勉强"；已写 console/state/model_pool_state.json。

# T10 测试环境禁 GPT-6
# 打开 fleet/projects/P-004/project.json → test_env.blocklist 含 "v3/gpt-6-astra"、
# admin_model=agnes-3.0-flash；model-pool.json → v3.env_scope=["prod"]。

# 全栈启动一键（幂等，含控制台/Manager/全员网关/池探活/CLI探活与最高权限启动行打印）
python E:\Code\AideanCompany\fleet\tools\restart_console_v3.py
```
