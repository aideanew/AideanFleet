# AideanFleet 运维指南

> 覆盖：安装、启动、配置、执行体接入、诊断、宿主内驱动。架构见 docs/架构.md。

## 1. 安装

要求：Windows 10/11 或 Linux，Python ≥ 3.10（建议 3.11/3.12）。

```bash
git clone https://github.com/aideanew/AideanFleet.git
cd AideanFleet
python -m pip install -e .
python -m pytest tests -q     # 可选：本地验证
```

前端 UI 构建产物已入库（`fleet/console/dist`），**没有 Node 也有界面**；改前端后才需要：

```bash
cd fleet/console/web && npm install && npm run build   # 产物输出到 fleet/console/dist
```

## 2. 启动

| 命令 | 行为 |
| --- | --- |
| `fleet init` | 向导：扫描已装 CLI（claude/codex/opencode）、探测模型 key 环境变量、生成 fleet.toml |
| `fleet up` | 进程管理：拉起 api（控制台）+ worker；控制台日志 `data/logs/api-*.log`，worker 日志 `data/logs/worker-*.log`；健康检查每 0.5s 轮询最长 20s；端口被自己旧实例占用则复用 |
| `fleet worker` | 只跑 kernel 侧 worker（`--loop` 常驻） |
| `fleet run` | 旧交互式启动（launch_core 9 步，兼容保留） |
| `python -m fleet.console.server` | 只起控制台（默认 127.0.0.1:3100，`FLEET_CONSOLE_PORT` 覆盖） |

启动失败排查顺序：看 `data/logs/` 最后 50 行（`fleet up` 失败时会自动打印）→ `fleet doctor`。

## 3. 配置

### 3.1 fleet.toml（新链路，推荐）

```toml
[workspace]
allowed_roots = ["E:/Demo"]          # 项目白名单；留空默认只允许仓库根目录

[models.agnes]                        # 模型池（OpenAI 兼容端点）
base_url = "https://apihub.agnes-ai.com/v1"
model_id = "agnes-3.0-flash"
api_key_env = "AGNES_API_KEY"        # 只写环境变量名，绝不写值
priority = 5

[roles.fe-1]                          # 角色 = 执行体链 + 模型链，不可用自动降级
harness = ["codex", "opencode"]
models  = ["agnes", "modelscope"]

[runtime]
scheduler = "auto"                    # auto | step | off
lease_minutes = 15                    # 认领租约时长
```

优先级（唯一一条规则）：**环境变量 > fleet.toml > 内置默认**。
当前可被环境变量覆盖的键：`FLEET_ALLOWED_ROOTS`、`FLEET_SCHEDULER`。
验证：`fleet doctor --config` 打印每个生效值及其来源（env / toml / default）。

### 3.2 .env（旧链路，兼容保留）

首次运行从 `.env.example` 复制生成；密钥只写 `${VAR}` 占位，真值放系统环境变量或 `secrets/.env`。
关键开关：`FLEET_SCHEDULER=1`（常驻调度，默认开，显式 0 关）、`FLEET_SCHEDULER_MODE=auto|step`、
`FLEET_ALLOWED_ROOTS`（逗号分隔白名单）、`FLEET_WATCHDOG`。

安全铁律：任何配置文件、日志、报告里都不得出现明文密钥；控制台保存配置时只接受 `${VAR}` 占位。

## 4. 执行体接入

```bash
powershell -ExecutionPolicy Bypass -File scripts\install_fleet_clis.ps1
# 幂等一键安装：cline/gemini/claude/codex/opencode（npm 全局）+ grok（官方安装器）
# 前置要求：Node.js >= 20 与 npm（脚本只检测不代装 Node）
fleet doctor          # 逐个 profile 跑 detect + auth_check；不可用的标红并给原因
fleet skills install  # 把 /fleet skill 装进 Claude Code / Codex / OpenCode（宿主内驱动）
```

**认证（装完必须手动做一次，脚本不代办）**：
- claude：终端运行 `claude`，首次启动按提示登录
- codex：`codex login`
- opencode：`opencode auth login`
- gemini：终端运行 `gemini`，首次运行 OAuth 引导
- cline / grok：各自首次运行引导

**降级与协议口径**：
- 角色绑定执行体链：链中任一 CLI 缺失/未登录，自动降级到下一个；全不可用 → 任务 blocked 并标红原因（UI 可见）。
- 只有 `model_protocol: openai` 的 harness 吃模型池（codex/opencode 注入 OPENAI_BASE_URL/OPENAI_API_KEY）；
  claude（anthropic 协议）使用宿主自身凭据。
- 新增执行体：在 `fleet/harness/profiles/` 加 `<name>.yaml`（字段见 docs/架构.md §5）。

## 5. 日常运维

- 日志：`data/logs/`（api/worker 按天滚动）。
- 数据：`data/kernel.db`（内核，WAL）、`data/fleet.db`（旧链路）、`data/evidence/<todo>/`（验收证据）。
- 事件导出：`python -c "from fleet.kernel import Kernel, export; ..."` → JSONL（outbox 发布语义）。
- 额度：`kernel.set_quota(role, n)` 每日限额；验证通过并写回才计费。
- Windows 防火墙异常：若本机 127.0.0.1 互连超时（ping 127.0.0.1 丢包），先查第三方安全软件写入的
  防火墙策略（`netsh advfirewall export` 备份后 `netsh advfirewall reset` 可恢复回环）。
