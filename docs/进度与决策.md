### 关键决策（为什么这么做）

1. **双内核并存而不是推倒旧链路**：console/manager/governance 有 344 个测试护着，一步切换风险大；
   kernel 与旧链路共享 models/executors 代码，旧链路逐步迁移（后续轮次）。
2. **tree 哈希重建本地仓库**：网络层 github.com 被阻断（TLS 指纹拦截），api.github.com 可用；
   用 tarball + Git Data API 重建，重建树哈希 `a4e9715a...` 与远端逐字节一致（本文件上一节可复现命令见 .zcode 任务脚本）。
3. **不做 UI 三页收敛**：本轮先把数据面（kernel 投影 API）接好，页面收敛留给下一轮
   （前端已有 10 页消费旧 API，强砍会破坏可用性）。
4. **`{python}` 占位符**：Windows Store 占位 stub 让裸 `python` 静默失败（本机实测 exit 非 0 无输出）；
   门命令统一走 Fleet 自身解释器，DB 里保留占位符便于跨机器迁移。
