# 控制台项目身份与联动修复方案大纲 v1（2026-09-17）

## 根因分析（基于最新真实代码）

| 现象 | 根因（代码位置） |
|---|---|
| 1. 输入"Test09171500"提示项目不存在 | `server.py` `api_session_create` 用 `db.get_project(project)` 校验，而 `get_project` 只按 **project_id**（如 P-007）查，不按 **name**（Test09171500）查（db.py:411-414）。锁屏候选 chips 显示的恰恰是 name（LockScreen.vue:78-80），点选后必失败 |
| 2. 项目不能切换 | TopBar.vue:34-36 项目徽标是 `cursor:default` 静态按钮；服务端无切换会话项目的 API；session 与 project 创建后绑定 |
| 3. 进度条显示"项目尚未开始执行" | plan store `started` = 任一任务 state≠'DRAFT'（plan.ts:38）。用户被锁在错误项目（AideanFleet，无任务）上，`plan.load` 拉到空计划 → started=false。P-007 的任务实际在 DOING/DONE |
| 4. 执行与控制台无联动 | 同源：执行事件全部写入 P-007，前端会话停留在其他项目；且锁屏无法进入 P-007（问题1）、进入后无法切过去（问题2） |

## 方案大纲

### 1. 后端：项目身份解析与切换 API
- 1.1 `fleet/core/db.py`：新增 `find_project(key)` —— 按 project_id 或 name 精确匹配返回项目（原子查询，id 优先）。
- 1.2 `fleet/console/server.py` `api_session_create`：解锁校验改用 `find_project`，session 记录 **project_id**（规范化，杜绝后续按 name 查不到）。
- 1.3 `fleet/console/server.py`：新增 `POST /api/session/switch {project}` —— 校验项目存在（id 或 name），更新当前会话的 project 为其 project_id，返回新 project 与 expires_in；记 `session:switch` 事件。
- 1.4 `/api/projects` 锁屏可用：保持会话保护不变（契约），但 `/api/session` POST 失败时错误信息带提示；锁屏候选列表改由 **豁免端点** `GET /api/projects/names`（仅返回 name+id 列表，无路径等敏感字段；服务仅监听 127.0.0.1）。

### 2. 前端：锁屏、切换、进度联动
- 2.1 `api/client.ts`：新增 `switchSession(project)`；新增 `listProjectNames()`。
- 2.2 `stores/auth.ts`：新增 `switchTo(project)` —— 调 switch API、apply 新 project、清空 execution/chat store。
- 2.3 `LockScreen.vue`：候选 chips 点击即直接解锁（不只填输入框）；加载 `/api/projects/names`。
- 2.4 `TopBar.vue`：项目徽标变为下拉（列出全部项目名），选择即调 `auth.switchTo` 并刷新 plan/events/WS。
- 2.5 `stores/plan.ts`：`started` 兼容后端任务状态；切换项目时 `runStartedAt` 重置后再 load（避免旧项目起点串台）。

### 3. 测试与验收
- 3.1 后端 pytest：`tests/core/test_session_project_identity.py` —— 按 name 解锁、按 id 解锁、切换会话项目、names 端点豁免（TDD：先红后绿）。
- 3.2 前端 build：`npm run build` 产出 dist，`vue-tsc` 类型检查通过。
- 3.3 浏览器实测（chrome-devtools MCP）：锁屏输入 "Test09171500" 解锁成功 → 顶栏显示该项目 → 进度条显示 P-007 真实任务进度（非"尚未开始执行"）→ 下拉切换到其他项目再切回 → 事件流/进度与新会话项目一致。
- 3.4 回归：现有 pytest 全绿（重点 tests/core/、tests/test_smoke.py）。

### 4. 交付边界
- 4.1 不改锁屏会话契约语义（token 三层兼容、TTL 不变）。
- 4.2 不动执行链（dispatcher/scheduler）与事件写入格式。
- 4.3 `/api/projects/names` 只在 127.0.0.1 监听前提下豁免，契约文档补一行说明。
